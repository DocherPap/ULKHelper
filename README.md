# 优雷卡助手 / ULKHelper

适用于《最终幻想14》国服卫月的优雷卡便捷插件，提供装备与材料统计、天气预报、地图和 FATE 提醒。

## 安装与打开

在卫月设置的“自定义插件仓库”中添加以下地址，保存并刷新插件列表，搜索 **优雷卡助手** 安装：

```text
https://raw.githubusercontent.com/DocherPap/MakoMaster/main/repo.json
```

安装后输入 `/ulk` 打开窗口。窗口支持拖动和调整大小，顶部有“物品统计”“天气预报”“地图 / FATE”“自动化”四个分页。

## 物品统计

统计主手、70级校服、优雷卡补正装备以及小黑衣 / 小红衣的持有情况和所需材料。

- 左侧选择按物品或职业分类，并勾选需要显示的职业或装备类别。
- 中间显示装备和强化阶段：亮绿色表示实际拥有，浅绿色表示已由后续阶段完成。
- 右侧显示材料持有量与需求，可切换“按目前进度”或“按总体进度”。可兑换材料悬停时显示换算需求，乱属性水晶按每个常风水晶约换取 3.5 个估算。
- 左、中、右三栏之间的分隔线可以拖动，调整各栏宽度。

库存范围包括背包、穿戴、兵装库、普通及高级陆行鸟背包、雇员、收藏柜和幻化柜。打开对应容器或与雇员交互后更新；尚未重新获取的来源使用上次缓存，并按角色分别保存。

来源状态中，“未获取”表示尚无记录，“已缓存”表示上次获取的记录，绿色“已更新”表示本次已读取。

## 天气预报

显示常风、恒冰、涌火、丰水四岛的当前及后续天气，以及下一时段倒计时。可选择显示 6、12 或 24 个时段，并切换本地时间或 UTC。

## 地图 / FATE

显示四岛地图、72 个 FATE 点位、触发小怪和特殊触发条件。

- 滚轮缩放地图，拖动平移，点击点位查看详情，也可按名字或简称搜索。
- 可跟随当前岛屿，选择是否显示幸福兔和点位简称。
- 点位显示预计刷新剩余时间、天气等待时间或天气剩余时间；当前活动同时显示进度和剩余时间。
- 可在游戏地图上标记位置，也可手动补记本次实例中 FATE 的出现时间。

每次进岛时查询一次众包发生记录，之后由本地观察更新，不周期查询或上传。未知记录不会推测，离岛后清空本次记录。刷新倒计时仅供参考，还需满足刷怪、天气等触发条件。

### 出现通知

勾选“发送通知频道”后，选择频道并编辑通知文字。默认关闭，默认频道为默语 `/e`，只提醒开启后新出现的 FATE。

默认文字：

```text
在<位置>发现<名字><se.1>
```

- `<位置>`：FATE 的可点击旗标位置，发送时会更新游戏中的旗标。
- `<名字>`：FATE 简称。
- `<se.1>`：游戏提示音标记。

支持喊话、呼喊、说话、小队、团队、部队、默语、调试默语、新人频道、PvP 战队、通信贝和跨服通信贝。默语与调试默语只在本机显示；调试默语不执行提示音标记。

## 自动化

自动化页提供“开始跟随伐木”，需要安装并启用 **vnavmesh**、**Rotation Solver Reborn**，以及 **BossMod 或 BossMod Reborn**。

岛内玩家名单每30秒更新一次，也可输入 `/ulk refreshplayers` 手动刷新。远处玩家可以选为车头，位置未加载时不会显示距离；攻击状态仅能确认客户端可观测到的玩家。

1. 在右侧“导航”中选择已拥有的坐骑，再从车头旁的岛民名单选择玩家并设为车头。
2. 点击“开始跟随伐木”，等待车头发送新坐标。未在战斗时召唤所选坐骑并出发，较远目标会尝试岛内水晶传送，无需 Lifestream。
3. 到达后下坐骑等待NM开怪，持续选中头目；需要等级同步时先同步，确认后才开启自动循环和BossMod移动。
4. 战斗结束后自动关闭本插件开启的控制，脱战后上坐骑；车头最新坐标附近有新NM则前往，没有则靠近最近水晶待机。待机时出现新NM可继续，战斗中收到新坐标不会中途转向。

左侧地图可点击NM并加入自动触发列表，最多3个，显示对应触发小怪说明，支持移除。“开始触发（未完成）”目前仅作界面预留，尚不执行刷怪或统计击杀数量。原“地图 / FATE”分页仍可独立使用。

点击“停止跟随伐木”结束流程；关闭窗口不会停止。更换车头、死亡或离岛时也会停止，重新登录或加载不会自动恢复。单次“开始导航到目的地”会在打完并上坐骑后结束，不持续跟随。

开始前请关闭已经运行的自动循环和BossMod AI；本插件只管理自己开启的控制，并在结束后恢复自己临时更改的配置。单次跟随最长2小时。坐骑、自动化开关和车头选择仅在当前会话保留。其他页面不需要这些战斗与导航插件。
