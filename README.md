# 优雷卡助手 / ULKHelper

适用于《最终幻想14》国服卫月的优雷卡便捷插件。0.3.0 提供常用功能、装备与材料统计、四岛天气与 FATE 地图、自动触发、跟随伐木、幸福兔寻宝、文理技能和 Discord 远程进岛。

## 安装与打开

在卫月设置的“自定义插件仓库”中添加以下地址，保存并刷新插件列表，搜索 **优雷卡助手** 安装。

```text
https://raw.githubusercontent.com/DocherPap/ULKHelper/main/repo.json
```

输入 `/ulk` 打开窗口。正式界面有“常用功能”“物品统计”“天气预报”“地图 / 自动化”“文理技能”五个分页，支持调整窗口大小与分栏宽度。

自动移动使用 vnavmesh。黄金港与跨服行程使用 Lifestream。战斗循环使用 Rotation Solver Reborn，战斗移动可选原版 BossMod 或 BossMod Reborn，游戏中同时启用其中一种。具体任务会检查对应依赖。

## 常用功能

- 自动前往黄金港的罗德尼，进入常风、恒冰、涌火、丰水四岛。
- 返回本岛营地，前往最近水晶挂机，较远行程可使用已解锁的岛内水晶。
- 购买 99 个优雷卡恢复药，包括前往商人、选择购物和购买确认。
- 选择拥有的坐骑，前往游戏地图旗标或旗标附近的 FATE。
- “自动等待开怪”选择附近 100 米内的活动 FATE，前往头目约 20 米处，确认开怪与等级同步后启用战斗。
- “吃 FATE”串联旗标附近 FATE 的导航、等待开怪与战斗。
- 持有“指引财宝”时，“自动寻找宝藏”执行一轮寻宝。
- 等级同步，发送元灵旗标，发送当前位置求救。
- 可选岛内喊话自动邀请、自动接受组队。
- 可选进入恒冰前的闪袭指环检查。未来 3 个现实小时内有薄雾且随身携带或装备指环时取消进岛。
- 可选靠近虚无冰雪龙 15 米时切换走路。
- 可选进岛后快速检查元灵，巡查可用水晶附近并返回营地。
- 紧急停止关闭本插件任务、自动移动和战斗控制。

## 物品统计

统计主手、70 级校服、优雷卡补正装备、小黑衣 / 小红衣的持有情况及强化材料。

- 按物品或职业分类，筛选 4.0 的 15 个职业与四类装备。
- 装备按每行五件居中显示，进度圆点区分实际拥有与已完成前置阶段。
- 材料按四岛分行，印章和织物独立一行。切换目前进度与总体进度，查看数量和进度条。
- 可兑换材料悬浮显示换算。常风水晶兑换乱属性水晶按约 3.5 倍估算。
- 左、中、右三栏可拖动调整宽度。

库存范围包括背包、穿戴、兵装库、普通及高级陆行鸟背包、雇员、收藏柜和幻化柜。打开对应容器或与雇员交互后更新，未重新读取的来源保留上次缓存，角色之间分别保存。

## 天气预报

显示四岛的当前及后续天气、时间区间与倒计时。可选择当前及后续 5、11、23 个天气，切换本地时间或 UTC。每段天气持续 23 分 20 秒，有特殊 FATE 触发条件的天气会高亮。

## 地图 / 自动化

显示四岛地图、72 个 FATE 点位、触发小怪、天气条件与发生记录。进岛自动切换地图，支持缩放、平移、还原视图、搜索、简称和幸福兔显示。

点位展示活动状态、预计刷新、天气等待或天气剩余时间，可在游戏地图插旗、手动补记或清除本次出现时间，也可自动前往。洞内目标优先使用活动 FATE 或已加载头目的实际高度。

进岛查询一次众包记录，后续由本地观察更新。预计刷新时间仍需结合小怪、天气等条件判断。幸福兔有独立的活动与刷新计时。

地图可显示当前实例已知的元灵、已观测触发怪区域和已保存路线。FATE 列表、岛民名单、触发队列和历史记录可折叠查看。

### FATE 通知

默认开启默语 `/e`，普通 NM 新出现时发送通知。切换频道后需要重新勾选。模板可编辑，默认如下。

```text
在<位置>发现<名字><se.1>
```

`<位置>` 为可点击旗标，`<名字>` 为 FATE 简称，`<se.1>` 为提示音。支持喊话、呼喊、说话、小队、团队、部队、默语、调试默语、新人频道、PvP 战队、通信贝及跨服通信贝。

### 自动触发

选择 FATE 或已观测触发怪区域可开始，也可建立队列，按当前位置优先处理最近目标。低于自身元素等级可选 3 个，同级至高 2 级可选 2 个，更高可选 1 个。

分别设置拉怪方式和路线，支持四种组合。

- **攻击拉怪**使用 RSR Manual，选择没有仇恨的触发怪。自动路线骑乘靠近时，近战和坦克在 3 米、远程和治疗在 10 米内下坐骑。预设攻击路线在起点确认下坐骑后出发。
- **路过拉怪**出发前尝试上坐骑，完成路线后下坐骑击杀。FATE 比自身元素等级低至少 2 级时禁用此方式。
- **自动路线**实时更新已加载触发怪，优先处理最近可拉目标。缓存够一波就跳过 FATE 中心。每批可选 1–20 只或无限；按 5 米宽的行进范围计覆盖数，附近 45 米内无可拉目标或仇恨减少时转入击杀。
- **预设路线**支持多条记录、命名和地图预览。在起点检测到 15 米宽的沿线范围内至少 3 只可拉怪后出发，抵达终点击杀，脱战后返回起点等待新怪。

击杀阶段使用 RSR Auto 与已有仇恨的目标，按配置启用 BossMod。预设路线拉怪期间由插件控制移动。移动中可尝试可用的加速、位移技能，位移结束后继续未完成路线。自动路线支持两秒位移不足一米时向侧后脱卡。

可设置击杀 50–300 只仍未触发时放弃，或不限数量。FATE 出现或达到阈值后结束本项，任务结束按所有权还原战斗插件设置。每阶段最多 5 分钟，每次任务最多 2 小时。

### 跟随伐木

从岛民名单或当前选中玩家设置车头，选择坐骑后显式开始。岛民名单支持手动刷新和每 30 秒刷新。车头保留在本次登录会话，可清除，登出后清空。

跟车接收车头喊话的新旗标，25 米内的重复坐标合并。附近有 NM 时靠近实际头目待机，没有 NM 时直接前往旗标。战斗中保留最新一个待处理坐标，战后优先处理，未收到新坐标则等待 3 秒再前往最近水晶。

开怪判断采用附近参与者三分之二正在攻击、头目血量低于 80% 或至少两名队友正在攻击。确认下坐骑及等级同步后启用 RSR Manual 与 BossMod，保持头目目标，战后关闭控制并尝试上坐骑。

## 幸福兔挖宝

显示恒冰、涌火、丰水参考点位和三种宝箱的特色掉落。手动使用胡萝卜后，根据位置、方向与距离筛选候选，剩一个时自动插旗。支持撤销、重置、手动补记提示与查看本轮线索，状态结束后重置本轮地图。

自动挖宝可选择本岛兔子 FATE、最少剩余时间和挖箱数量。满足门槛的多个活动中优先选剩余时间最短的一场。未出现时前往所选活动附近待机。获得“指引财宝”后接续寻宝，使用所选坐骑，途中暂停取新线索，到达后按胡萝卜提示继续前进。

“挖 N 个”按系统确认挖出宝箱计数，0 表示不限。也可从常用功能单独开始一轮自动寻找宝藏。宝箱由玩家手动打开，附近箱体的实际位置会用于新增或校准本机参考点。

## 文理技能

碎晶鉴定展示 9 类碎晶可能获得的记忆。点击查询价格，获取当前服务器、当前大区和国服的 Universalis 最低在售价，缺失数据显示未知。

技能合成列出 56 个文理技能的参考配方，按碎晶价格估算成本。☆收藏后，★技能置顶，其余按编号排序。碎晶和记忆名称后显示已读取库存数量，未知数量保持未知。

## Discord 远程进岛

展开“常用功能 → Discord 远程进岛”，填写自己的 Discord 用户 ID 和 Bot Token，连接后私聊机器人发送“状态”。需本机 Python 与 discord.py，完整配置见 [Discord 使用说明](DiscordBridge/README.md)。

支持服务器、岛屿和指定 FATE 的组合、补充未完整的指令、Lifestream 跨服、罗德尼报名、进岛后监听和参加一场目标活动。可选锁定目标后喊话组队及任务期间自动组队，完成后报告本机捕获的结果与奖励消息。发送“停止”或在游戏内紧急停止可取消任务。

凭据使用当前 Windows 用户的 DPAPI 加密保存，可在界面清除。安装包包含桥接脚本，插件加载后接入默认关闭。

## 设置与停止

窗口、栏宽、筛选、通知模板、坐骑、路线和功能偏好保存在插件配置目录，更新时继续使用。任务运行状态不会在更新或重新登录后自动恢复。

`/ulk stop` 停止本插件任务；`/ulk refreshplayers` 刷新岛民名单；`/ulk entrance` 前往本岛营地。

完整功能验收清单见 [0.3.0 功能测试清单](https://github.com/DocherPap/ULKHelper/blob/main/docs/FEATURE_CHECKLIST_0.3.0.md)。
