# 独立单人调试分支

分支固定为 `codex/solo-debug-tests`。按用户明确要求，先在main的c8996e9打包正式0.1.0（自动化禁用、无第五页），再在本分支恢复自动化和增加测试页。此分支的改动不得提交/合并main，不推送或发布正式库链。正式ZIP SHA256为 `20d494fcc2398a38bc586e0ca92c42a77823039df3868b3abd92a40116d28d30`。

调试程序集版本仍0.1.0.0，InformationalVersion为0.1.0-debug.2，清单显示“优雷卡助手（调试分支）”。InternalName及配置路径保持ULKHelper以沿用设置；不要同时加载正式版和调试版。

## 单人操作

1. 安全营地：选择已拥有坐骑，单次上/下坐骑。只提交一次请求，12秒内确认真实骑乘状态；全流程60秒上限。
2. 水晶：先手动走到本岛源水晶5米内，关闭其他菜单，选择另一座已解锁水晶，点击单次水晶传送。单独菜单适配器拥有自己的交互，不经过vnavmesh或战斗插件；可先下坐骑，菜单15秒，落地45秒，总60秒，不盲选未解锁条目、不自动回程。不需要车头或队友。
3. 导航：测试前往入口营地，使用既有5分钟单次导航，需要vnavmesh。顶部停止按钮同时取消本插件测试和自己的导航；已提交的传送无法撤回，落地不恢复任务。
4. 设置：输入测试文字保存，再从磁盘JSON重读或重载插件核对。窗口栏宽/物品筛选/模板也可修改并重载查看。
5. 现场状态按钮只读，复制报告只写剪贴板，包含读取时间、区域/地图/位置、近处Aetheryte/EventObj种类及BaseId、实际距离、vnavmesh状态、RSR/BossMod开关、绑定NM与最近40条测试记录。不会发聊天或打开循环。

测试/导航/跟随互斥；切区、角色变化、战斗/死亡等不安全状态和卸载结束测试。同岛自身传送的预期黑屏可短暂沿用稳定角色/地图上下文；原生指针不跨帧保存。独立导航和测试传送期间允许自己打开的水晶菜单占用，避免选择菜单后到黑屏前被自己的交互状态打断；战斗仍取消。

真实开怪、等级同步和战后骑乘仍需遇到NM；离线验证不启用真实RSR/BMR、不执行骑乘/传送或发言。默认/1000×520页面离线检查，真实ImGui读取/骑乘/跟随按钮通过模拟提供者验证；166项自动化、10项设置检查通过。
