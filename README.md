# 优雷卡助手 / ULKHelper

适用于《最终幻想14》国服卫月的优雷卡便捷插件，提供装备与材料统计、天气预报、地图和 FATE 提醒。

## 安装与打开

在卫月设置的“自定义插件仓库”中添加以下地址，保存并刷新插件列表，搜索 **优雷卡助手** 安装：

```text
https://raw.githubusercontent.com/DocherPap/ULKHelper/main/repo.json
```

安装后输入 `/ulk` 打开窗口。窗口支持拖动和调整大小，顶部有“常用功能”“物品统计”“天气预报”“地图 / FATE”“文理技能”“自动化”六个分页。

## 常用功能

可前往黄金港的罗德尼、进入四岛、返回岛内营地、前往最近的水晶、购买 99 个优雷卡恢复药。黄金港传送及第一防波堤接驳使用 Lifestream，步行寻路使用 vnavmesh。

在游戏地图上插旗后可前往该坐标或附近的 FATE。“自动等待开怪”会选择 100 米内的活动 FATE，靠近首领后等待开怪，并按需同步等级后开启 RSR 和 BossMod AI。紧急停止会停止移动和战斗自动化。

可单独开启岛内喊话自动邀请和自动接受组队。也可喊话发送本岛最近一次记录的元灵旗标，或发送当前位置求救。

## 物品统计

统计主手、70级校服、优雷卡补正装备以及小黑衣 / 小红衣的持有情况和所需材料。

- 左侧选择按物品或职业分类，并勾选需要显示的职业或装备类别。
- 中间显示装备和强化阶段：亮绿色表示实际拥有，浅绿色表示已由后续阶段完成。
- 右侧显示材料持有量与需求，可切换“按目前进度”或“按总体进度”。可兑换材料悬停时显示换算需求，乱属性水晶按每个常风水晶约换取 3.5 个估算。
- 左、中、右三栏之间的分隔线可以拖动，调整各栏宽度。

库存范围包括背包、穿戴、兵装库、普通及高级陆行鸟背包、雇员、收藏柜和幻化柜。打开对应容器或与雇员交互后更新；尚未重新获取的来源使用上次缓存，并按角色分别保存。

来源状态中，“未获取”表示尚无记录，“已缓存”表示上次获取的记录，绿色“已更新”表示本次已读取。

## 天气预报

显示常风、恒冰、涌火、丰水四岛的当前及后续天气，以及下一时段倒计时。可选择显示 6、12 或 24 个时段，并切换本地时间或 UTC。

## 地图 / FATE

显示四岛地图、72 个 FATE 点位、触发小怪和特殊触发条件。

- 滚轮缩放地图，拖动平移，点击点位查看详情，也可按名字或简称搜索。
- 可跟随当前岛屿，选择是否显示幸福兔和点位简称。
- 点位显示预计刷新剩余时间、天气等待时间或天气剩余时间；当前活动同时显示进度和剩余时间。
- 可在游戏地图上标记位置，也可手动补记本次实例中 FATE 的出现时间。

每次进岛时查询一次众包发生记录，之后由本地观察更新，不周期查询或上传。未知记录不会推测，离岛后清空本次记录。刷新倒计时仅供参考，还需满足刷怪、天气等触发条件。

### 出现通知

默认开启默语 `/e` 通知，只提醒之后新出现的 FATE。切换频道后自动关闭通知，需要重新勾选才能向新频道发送；通知文字可自行编辑。

默认文字：

```text
在<位置>发现<名字><se.1>
```

- `<位置>`：FATE 的可点击旗标位置，发送时会更新游戏中的旗标。
- `<名字>`：FATE 简称。
- `<se.1>`：游戏提示音标记。

支持喊话、呼喊、说话、小队、团队、部队、默语、调试默语、新人频道、PvP 战队、通信贝和跨服通信贝。默语与调试默语只在本机显示；调试默语不执行提示音标记。

## 兔子挖宝

显示恒冰、涌火、丰水的142处参考挖宝点和青铜/白银/黄金兔箱的经典特色掉落，不含金币、魔晶石等通用品。

“地图 / FATE”页的列表上方显示挖宝状态，挖宝点和提示范围与 FATE 共用地图；“显示简称”旁的“显示挖宝点位”可控制点位叠加，点击“线索 / 掉落”查看手动补记、历史和特色掉落。获得“指引财宝”状态后自动监听。自行使用胡萝卜，每次提示会按当前位置、提示方向和距离缩小候选；只剩一个时自动在游戏地图插旗。多个候选会在插件地图高亮，支持缩放、平移、撤销和手动补记。

坐标有取整误差，推测保留少量距离容差；若线索矛盾会暂停插旗。不会自动移动、使用道具或打开宝箱。幸福兔状态结束后自动清空线索、恢复全部点位并还原地图视图；离岛、换角色或房间后也清空线索。

## 文理技能

碎晶鉴定展示9类碎晶可鉴定的记忆，点击查询价格可获取当前服务器、当前大区及国服的Universalis最低在售价。众包报价可能过期，缺少报价时显示未知。

技能合成展示56个文理技能的全部参考配方。点击☆收藏，★技能置顶，其余按编号排序，收藏自动保存。成本按来源碎晶价格估算，未计随机鉴定损耗，不能当作精确成本。

## 自动化

左侧选中NM或小怪色块后可直接开始，也可先加入列表。有列表时优先处理离玩家最近的FATE。低于自身元素等级可选3个，同级至高2级可选2个，更高可选1个；混选取最严格限制。色块仅显示本次入岛已观测区域，未加载区域不会凭空补全。

可设置每批拉怪1–20只或无限，以及击杀50–300只仍未触发时放弃或不限数量。点击“自动触发”开始，点击停止结束。普通模式需要vnavmesh、Rotation Solver Reborn和BossMod Reborn。

- 普通模式到达FATE中心后，立即用已加载的小怪均分波次。没怪时原地等待。BMR靠近，RSR负责拉怪和击杀。脱战后继续当前FATE的下一波。
- 特殊模式先记录起点、途径点和终点，选好坐骑后沿记录路线骑乘拉怪，到终点下坐骑击杀，再返回起点等待刷新。凯西、阴阳、狼、彭女士和守望者默认此模式，每项都可手动切换。
- 已知点位会做快速路径排序；特殊路线保留手动记录顺序。无有效路线时不会开始特殊触发。

FATE出现或达到放弃数量后结束对应计划，不自动攻击NM。无限仅取消数量限制，每阶段仍有5分钟、会话2小时上限。自动触发与跟随、导航互斥。

跟随伐木需选择车头和坐骑，再显式开始；需要vnavmesh、Rotation Solver Reborn及BossMod/BossMod Reborn。停止按钮可结束，切区/死亡/卸载也会停止，不自动恢复。

地图页选择当前岛的FATE后，可点击“自动前往”。移动需要 **vnavmesh**，较远路线会尝试岛内水晶传送，不需要Lifestream或战斗插件。自动化页停止按钮或 `/ulk stop` 可取消移动，离岛、死亡或状态异常也会停止。

输入 `/ulk entrance` 可前往入口营地。只移动到水晶附近，不离开副本，不自动解锁水晶。

## 设置保存

窗口位置、大小、栏宽、页签、物品筛选、天气显示、地图显示、通知频道和模板、所选坐骑、各角色车头、自动触发参数/模式及记录路线会自动保存到卫月插件配置目录的 `ULKHelper/settings.json`。正常更新插件不会覆盖此文件。

运行中的移动、跟随、战斗、临时触发计划和副本发生记录不会在更新或重新登录后自动恢复。库存仍按角色分别保存。
