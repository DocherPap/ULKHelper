# 自动触发（开发版）

「自动触发」按钮下方显示当前特殊 FATE 的路线选择。默认名称为路线1、路线2等，可输入名称并点击保存，保存空名称会恢复默认编号。「自动循环」和「BMR AI」默认开启并分别保存。关闭自动循环时需手动打怪，普通模式关闭 BMR AI 时需手动靠近。特殊模式开启 BMR AI 时仍在终点原地击杀。

更新：2026-11-03。用户已授权实际刷怪流程；默认不运行，点击“自动触发”才开始。本次没有发布或覆盖0.1.1安装包。

## 使用

在自动化左侧点击NM或已观测的小怪色块。空列表可直接按“自动触发”，会加入当前选中的有效FATE并开始。没有有效手选目标时，按钮显示并直接启动当前岛水平100米内最近、尚未出现且具备触发规则的FATE。特殊模式需已有路线。此距离按FATE点计算。有列表时，开始和完成每项后都按玩家当时位置选择最近的剩余FATE。按游戏元素等级判断：低于自身可选3个，同级至高2级可选2个，更高只可选1个；混选取最严格限制。等级未知不开始，不使用职业等级代替。UI及框架执行入口分别验证。

- 每批拉怪：1–20，最后一档无限。
- 放弃阈值：50、100、150、200、250、300、无限，按每个FATE本次任务的本地观测击杀分别累计。
- 普通模式：到达FATE中心后立即用已加载的小怪分波并开始拉怪。没有符合条件的已加载小怪时原地等待刷新。每秒更新半径100米内符合名称ID与元素等级的已加载小怪坐标，已死、不可选中、已交战或已拉到的怪从待拉缓存排除。按近邻和局部改良后的顺序分波，波数向上取整，余数分到最后几波。例如25只、上限10只时为8／8／9。每波从本波缓存选玩家水平45米内最近的可拉目标，确认仇恨才拉下一只。拉满或附近已无可拉目标时，直接击杀已有仇恨的怪。脱战后若45米内没有可拉目标，则向最近的合格已加载触发怪移动。途中有可拉目标进入45米时结束该段寻路，继续拉怪。前往中心或远处小怪时，脱战且已选坐骑就先尝试上坐骑，最多三次，失败后步行。需要拉怪或击杀时先确认下坐骑。脱战后继续同一FATE的下一波，直到FATE出现或达到上限。
- 特殊模式：在实际位置点“新建路线 / 记录起点”，沿途点“追加途径点 / 终点”。每个FATE可保存多条路线，路线下拉框切换地图预览和下一次执行所用路线，旧版单条路线会显示为路线1。首点为起点，末点为终点，执行需至少2点、最多128点，保留XYZ高度。整条记录路线一次交给移动跟随器，骑乘沿途引怪，抵达终点后下坐骑击杀。脱战后返回起点，等待60米内新出现的触发怪。达到批次上限也继续走完记录路线。
- 默认特殊：常风帕祖祖1329、拉玛什图1338，恒冰娄希1364、凯西1365，涌火阴阳1402、狼1403、彭忒西勒亚1404，丰水马王1418、守望者1423。其余默认普通，每项可手动切换。特殊模式需要先记录路线。

FATE出现或达到放弃数量后不再拉新怪；若已战斗，先处理本批触发怪，脱战后移除该计划。不会自动攻击出现的NM。本会话曾看见某计划FATE出现，即使后来从表中消失也不会重新当作未触发。

## 地图分布与路线

色块为本次入岛实际观测到的、名称ID与等级符合既有65条规则的非战斗小怪位置，按20米网格聚合，不是精确出生区，也不覆盖未加载区域。鼠标点击色块选择对应NM；普通触发的初始目的地是所选FATE的地图点。最多4096格，切区/角色变化清空，不持久化怪物位置。记录路线另以编号折线显示。

没有导入调研仓库的GPL数据，没有新增联网请求。已核实怪物名称/等级来源仍是 `Fates/FateTriggers.cs` 的MIT目录及本机BNpcName表；地图研究见 `MOB_DISTRIBUTION_RESEARCH.md`。

缓存中的怪物采用近邻顺序和最多3轮2-opt局部改善。分波保留位置相同的不同怪物。它优化直线距离近似，不宣称全局最优或实际寻路耗时最短。普通模式到点以水平5米为准，忽略高度差。已发出的路线结束时视为该段完成并开始拉怪。每段仍由vnavmesh验证地面与完整路径；记录点使用真实高度，无高度的FATE中心查找地面。特殊途径点保留用户顺序，避免优化重排跨越危险地形。

## 交互与限制

`AutoTriggerHelper`是纯状态机，`TriggerGameReader`负责框架线程只读快照，`AutomationHelpers`处理UI命令队列、互斥与持久化。RSR负责攻击，普通模式战斗移动由BossMod Reborn AI负责，拉怪用Manual与全部目标范围，临时禁止RSR自由选目标，由插件选本波最近的未交战、无仇恨怪。击杀用Auto、HighHP与有仇恨目标范围。插件每次观察都按本地仇恨列表确认当前目标，若脱离可击杀名单则重新选中名单内的怪。RSR范围由临时覆盖提供。BMR沿用用户当前配置的靠近距离。BMR仅在普通战斗阶段接管移动，vnavmesh负责首次前往FATE中心和脱战后接近较远的触发怪。显式开始保存并暂停原开关，写入BMR配置前保存旧值，结束按提供者身份与最后写入值还原。特殊模式仍沿记录路线骑乘拉怪，在终点用RSR击杀。

仇恨证据来自本机UIState.Hater战斗敌对列表或怪物正在以自己为目标。拉怪目标连续6秒未明显接近且血量未下降，或25秒未确认仇恨时，暂缓该目标30秒并继续挑选本波目标。只有连续观测到已拉怪活到死才计入放弃数量，怪物消失、首次见尸体和采样断开超过2秒均不算击杀。该数量是本地观察，其他玩家可能参与击杀。没有可确认的敌人时暂停循环并等脱战。

每阶段5分钟、会话2小时；骑乘/下坐骑最多3次，间隔3秒。无限只取消数量限制，不取消时间保护。手动停止、切区、死亡、登出、依赖丢失或外部路线接管均停止，不恢复。与跟随伐木、单次导航、调试页动作测试互斥；调试页只读现场报告仍可使用，已加入触发状态和观测区域数。

参数、模式和记录路线保存在配置目录 `settings.json`（trigger.batch/abandon/modes/routeSets/showMobs）。不恢复进行中的计划/任务、怪物仇恨或击杀数量。现有众包入岛一次读取及通知策略不变。

## 验证与单人测试

trigger-waves.13 的224项自动化检查通过，覆盖最近优先、先巡查再开启循环、8／8／9分波、巡查中新增怪、最高血量目标、50只上限、FATE出现、特殊路线及停止清理。使用模拟导航、坐骑和循环。

实际游戏内未验证，建议先单人测试：

1. 选低等级、无天气限制的NM，每批1只、放弃50。确认选中即可启动，观察到达中心后直接选怪、缓存数、RSR Manual／Auto切换及BMR接近距离。手动停止后对比原设置。
2. 对同一NM手动切特殊模式，步行记录短的起点→途径→终点，确认坐骑路过不攻击、到终点下坐骑、击杀后回起点等待。
3. 在找路、等待坐骑及击杀期间分别停止；确认不继续移动/开循环。调试页读取现场后复制报告。
4. 保存路线、模式和参数后重载插件，确认偏好还在且任务没有自动恢复。

实际地图网格、职业循环能否主动攻击、仇恨建立/脱战和怪物重生均需游戏内反馈，不以编译或模拟通过代替。

## trigger-fix.4现场纠错

2026-11-03用户报告证明IBattleNpc.Level是普通战斗等级70，不能匹配优雷卡8级小怪。现统一从本机Character.GetForayInfo()->Level读取元素等级，用于名称/等级筛选与击杀统计；0/空指针或异常等级保持未知。源码接口参考 https://github.com/aers/FFXIVClientStructs/blob/main/FFXIVClientStructs/FFXIV/Client/Game/Character/Character.cs ，使用本机配套程序集编译，不硬编码国际服偏移。现场常风鸟妖NameId6822与规则8级已核对。
