# 常用功能

- 「恒冰靠近冰雪龙时自动走路」默认关闭并保存。开启后进入存活的虚无冰雪龙 15 米三维范围时检查一次客户端走路状态，必要时开启走路。离开后保留当前移动模式。国服本机 BNpcName 表核对虚无冰雪龙 7473。

- 「快速检查元灵」默认关闭，保存勾选状态。开启后每次进岛从营地开始检查，依次传送到当前菜单允许且尚未检查的水晶。落地后等待两秒，汇总水晶周围100米内当前可见的元灵，沿用地图观察记录。跳过未解锁水晶，检查完返回营地。回程复用营地导航，有收益时传送，无可用传送时步行。紧急停止、关闭选项、切区、战斗或倒地会停止流程。巡查限时三分钟，回程限时五分钟。

- 「进入恒冰之地前检查闪袭指环」默认关闭，选项自动保存。开启后报名恒冰前检查当前及未来三现实小时的薄雾。命中时核对四个随身背包、穿戴栏和兵装库戒指栏。携带闪袭指环时取消自动参加并本地提醒。天气未知或有薄雾但库存无法确认时停止自动参加。国服本机游戏表核对闪袭指环 Item 36121、薄雾 Weather 4。

- 「自动前往入口」以黄金港罗德尼为终点。「进入」四岛复用该行程，再选择可用的对应岛屿菜单并验证最终区域。外岛行程通过 Lifestream 前往黄金港和第一防波堤。已经在罗德尼附近时直接步行。当前在岛内时先自行离岛。
- 返回营地跳过无 FATE 的两秒等待，明显节省路程时尝试通过已解锁水晶传送，落地后直接继续。最近水晶待机只寻路。坐标和 FATE 寻路使用游戏地图旗标，FATE 必须在旗标 50 米内并已出现。两种寻路共用岛内坐骑处理。
- 等待开怪选择 100 米内最近的活动 NM，需读到其可选中的首领，向距首领 20 米的位置靠近。复用跟随伐木的开怪证据、同步判断、战斗控制与清理。
- 购买恢复药先核对补给负责人和已打开商店，确认唯一的 300 金币普通品质商品后提交一次 99 件购买。以库存增加 99 且金币减少 29700 验证完成。未确认结果时不自动重试。
- 购物和进岛可推进已交互 NPC 的前置对话，读取普通菜单与图标菜单的可用条目，确认时调用当前按钮注册的事件。购买确认需要匹配原商店、恢复药和 99 件交易。进岛确认需要当前窗口出现所选岛名。遇到未识别窗口时，超时状态附当前窗口及可见文本。
- 自动邀请与自动接受默认关闭，选项独立保存，只在四岛生效。自动邀请匹配修剪两侧空白后全为半角数字 1，或含连续三个半角 1 的喊话。邀请按岛内玩家实体 ID 发出并节流。自动接受每个已观察到的邀请只处理一次。
- 元灵喊话使用本岛地图最近记录的元灵，插旗后发送 `<flag>yl`；求救发送 `<pos>999`。紧急停止同时停止本插件任务、vnavmesh、RSR 和 BossMod AI，并关闭自动组队选项。

## 游戏内待测

- 单人验证黄金港接驳、接近罗德尼、四岛选项及确认窗口。遇到未识别的菜单会等待超时并显示状态。
- 单人验证各岛商店购买，尤其是涌火之地未加载 NPC 时的寻路。每次成功测试消耗 29700 金币。
- 单人验证旗标、坐骑、水晶待机以及紧急停止；在活动 NM 附近验证等待、同步和战斗接管。
- 与一名队友验证喊话匹配、邀请去重、自动接受以及岛外禁用。确认喊话模板在实际聊天窗口正确展开。

测试分支「自动寻找宝藏」仅在恒冰、涌火、丰水拥有指引财宝时启动一轮，接续已有线索或使用幸运胡萝卜后自动寻路；定位后提示手动开箱，不进入下一场兔子 FATE。
