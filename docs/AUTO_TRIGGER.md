# 自动触发（开发版）

更新：2026-11-03。用户已授权实际刷怪流程；默认不运行，点击“自动触发”才开始。本次没有发布或覆盖0.1.1安装包。

## 使用

在自动化左侧点击NM或已观测的小怪色块，加入触发列表。按游戏元素等级判断：低于自身可选3个，同级至高2级可选2个，更高只可选1个；混选取最严格限制。等级未知不开始，不使用职业等级代替。UI及框架执行入口分别验证。

- 每批拉怪：1–20，最后一档无限。
- 放弃阈值：50、100、150、200、250、300、无限，按每个FATE本次任务的本地观测击杀分别累计。
- 普通模式：优先寻找附近100米内已加载的匹配触发怪；无目标时先访问本次已观测区域，再围绕选中点45米半径的8点巡查。逐只接近并用RSR Manual建立仇恨，确认怪物以自己为目标后关闭循环继续拉怪；达到上限或附近没有新目标时停止导航，开启原地循环击杀，脱战后继续。多计划按批次轮换，空巡查圈完成后切换下一项。
- 特殊模式：先在实际游戏位置点“记录起点”，再沿途点“追加途径点 / 终点”；首点为起点、最后一点为终点。至少2点、最多128点，保留XYZ高度。选择已拥有坐骑，骑乘依序经过记录点，不开启攻击；达到数量上限后直接走终点，下坐骑确认后原地击杀。脱战后骑乘返回起点，等路线附近已加载怪物出现再出发。
- 凯西1365、阴阳1402、狼1403、彭忒西勒亚1404、水晶龙1423默认特殊；其他普通。每项均可切换。没有记录的特殊路线拒绝执行，不编造默认路线。

FATE出现或达到放弃数量后不再拉新怪；若已战斗，先处理本批触发怪，脱战后移除该计划。不会自动攻击出现的NM。本会话曾看见某计划FATE出现，即使后来从表中消失也不会重新当作未触发。

## 地图分布与路线

色块为本次入岛实际观测到的、名称ID与等级符合既有65条规则的非战斗小怪位置，按20米网格聚合，不是精确出生区，也不覆盖未加载区域。鼠标点击色块选择对应NM；该区域可作为本次普通巡查中心。最多4096格，切区/角色变化清空，不持久化怪物位置。记录路线另以编号折线显示。

没有导入调研仓库的GPL数据，没有新增联网请求。已核实怪物名称/等级来源仍是 `Fates/FateTriggers.cs` 的MIT目录及本机BNpcName表；地图研究见 `MOB_DISTRIBUTION_RESEARCH.md`。

已知怪物/观测点采用近邻顺序和最多3轮2-opt局部改善，每次最多128点。它优化直线距离近似，不宣称全局最优或实际寻路耗时最短。每段仍由vnavmesh验证地面与完整路径；记录点和实际怪物使用真实高度，无高度的FATE巡查点才查找地面。特殊途径点保留用户顺序，避免优化重排跨越危险地形。

## 交互与限制

`AutoTriggerHelper`是纯状态机，`TriggerGameReader`负责框架线程只读快照，`AutomationHelpers`处理UI命令队列、互斥与持久化。RSR负责攻击；使用现有战斗适配器的独立原地模式，不开启BossMod AI移动。启动依赖检查仍沿用RSR及BossMod/Reborn现有适配器，显式开始先关闭已有循环/AI。只清理自身拥有的控制。

仇恨证据当前采用触发怪TargetObjectId指向自己；未确认不把路过当作已拉到。目标25秒未建立仇恨停止。怪物消失、首次看见尸体、采样断开超过2秒均不算击杀；选中拉怪目标或已拉怪的活到死转换才累计。该数量不是服务器触发进度或独占击杀归属；其他玩家可能参与击杀。无法加载/确认的战斗敌人不会被当作已清完。

每阶段5分钟、会话2小时；骑乘/下坐骑最多3次，间隔3秒。无限只取消数量限制，不取消时间保护。手动停止、切区、死亡、登出、依赖丢失或外部路线接管均停止，不恢复。与跟随伐木、单次导航、第五页动作测试互斥；第五页只读现场报告仍可使用，已加入触发状态和观测区域数。

参数、模式和记录路线保存在配置目录 `settings.json`（trigger.batch/abandon/modes/routes/showMobs）。不恢复进行中的计划/任务、怪物仇恨或击杀数量。现有众包入岛一次读取及通知策略不变。

## 验证与单人测试

离线200项自动化检查（新增34项），覆盖等级/混选、模式默认、路径优化、拒绝无路线、明确启动、普通拉怪、批量原地战斗、50只放弃、尸体排除、特殊骑乘到终点、击杀后回程、等待/刷新、停止/切区/死亡/超时。101项FATE检查、12项设置检查通过，Debug/Release均0警告0错误。默认/1000×520同一ImGui页面预览及真实模拟鼠标点击“自动触发”通过；所有模拟使用假导航/坐骑/循环，不调用游戏。

实际游戏内未验证，建议先单人测试：

1. 选低等级、无天气限制的NM，每批1只、放弃50。检查小怪色块、最近目标选择、仇恨确认和一批结束后循环，再手动停止。
2. 对同一NM手动切特殊模式，步行记录短的起点→途径→终点，确认坐骑路过不攻击、到终点下坐骑、击杀后回起点等待。
3. 在找路、等待坐骑及击杀期间分别停止；确认不继续移动/开循环。第五页读取现场后复制报告。
4. 保存路线、模式和参数后重载插件，确认偏好还在且任务没有自动恢复。

实际地图网格、职业循环能否主动攻击、仇恨建立/脱战和怪物重生均需游戏内反馈，不以编译或模拟通过代替。
