# 优雷卡助手 0.0.1

- 装备与材料统计：主手、70级校服、元素补正、小黑衣 / 小红衣；按物品或职业筛选。
- 库存来源包括玩家背包/穿戴、兵装库、陆行鸟背包、雇员、收藏柜和幻化柜；打开对应容器后更新，未加载来源使用上次缓存。
- 四岛天气预报、游戏地图、72个FATE点位与触发说明、预计刷新和天气倒计时。
- 每次进岛仅查询一次官方众包记录，不周期轮询或上传。
- FATE 出现通知默认关闭，默认频道为默语 `/e`；支持自定义模板和可点击旗标位置。
- 自动化页位于最后，标为“施工中”，保留独立 helper 调试入口，尚未整合自动跟车。

适用国服 Dalamud API 15。输入 `/ulk` 打开。手动导航 helper 可选依赖 vnavmesh，其余功能无需该插件。

这是首个预览版，已经构建及离线检查，尚未完成游戏内实测。倒计时为参考估计，不代表必定刷新；库存来源需要实际打开获取。保留安装包中的 ThirdPartyNotices。
