# 0.3.0 功能测试清单

本表为游戏内人工验收清单。未勾选表示尚未验收。可按“编号、通过/失败、实际表现”反馈；失败时附岛屿、职业、元素等级、使用的 BossMod 版本及构建编号。涉及其他玩家的用例单独标注。

建议先测试界面、库存、导航和停止，再测试单轮寻宝、自动触发、跟车及 Discord。原版 BossMod 与 Reborn 分别启用测试。
