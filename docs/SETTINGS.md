# 设置持久化

2026-11-03。`SettingsStore` 使用 `IDalamudPluginInterface.GetPluginConfigDirectory()/settings.json`，独立于DLL/安装ZIP，正常更新不会覆盖。写入先落临时文件后替换，每秒最多一次，卸载强制提交；框架线程定期提交，因此关闭窗口不遗失最后一次设置修改。

保存物品分类/职业筛选/材料统计口径、天气时段数/UTC、地图岛屿/跟随/简称/幸福兔/缩放/中心/搜索、通知开关/频道/模板、窗口位置/尺寸/页签、左右栏宽、坐骑、各角色车头和玩家搜索。栏宽通过注册本插件表ID后提取对应ImGui表节，只恢复这些表，不写入其他插件的窗口/表布局。ImGui没有调整的默认表可以没有保存节。

未知根键保留；新键缺失用默认值；类型不兼容的键回退默认。损坏JSON先保留 `.invalid-<时间戳>` 原文，再允许写新配置；无法备份时只读保留原件并记录错误。离线9项设置检查验证重载、列表/Vector2、未知键、类型回退、原子提交和损坏恢复。真实ImGui拖动栏宽和页面设置经JSON往返检查通过。

监听、跟随、战斗、移动等运行状态不序列化，不自动开始或恢复；名单、临时触发计划、击杀计数、副本FATE历史属于运行数据，继续按原入场/角色规则清理。库存独立按角色保存。

通知新默认为开启默语/e；恢复已有设置时尊重原选择和开关。更换频道自动关闭（包括切回默语），只有再次勾选才启用新频道；启用/重入仍建基线，不补报历史，不发离线测试消息。
